# Hi! 👋

Hello! This cli is for creating Userfront users and getting JWT tokens for Userfront users. This is useful when testing backend services and you don't have a user interface to do this manually or don't want to worry about it

# Usage 🔬

Print out the cli usage text like so to see all options

```sh
node ./index.js --help
```

When creating a new user or authenticating with an existing one, a JWT will printed to stdout and stored in a file called "jwt.txt"
